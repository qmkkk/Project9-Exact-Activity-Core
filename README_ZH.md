# Project9 核心代码有限公开版

本仓库只公开目标条件联合计数关系、预算支持过滤、局部连接可行性接口、
独立正确性检查、一个解释样例和实验汇总数据。

完整 SAT 求解器集成、解释子句实现、全部实验脚本和原始日志、理论证明、
研究报告及开发历史保留在本地交接包，不在此仓库公开。
因此，本公开子集能够验证核心局部关系，但不能单独复现完整求解器的性能表。

Linux/WSL 下运行 `python3 tools/check_core.py` 即可编译并检查；
仅需 Python 3.10+ 和 GCC/Clang，无需安装 Python 依赖。

接口范围为 2、3、4 输入；真值行 0归一化为0，前驱信号为非常量。
预算为扣除其余节点安全下界后的剩余值。非空支持不等于完整电路可实现。
静态缓存要求串行调用。详细语义见英文 README 和头文件。

汇总数据保留超时、不利实例和比较口径。通用表传播器与专用内核性能接近，
不主张专用内核本身独立大幅领先，也不把活动度代理量称为实测物理功耗。
研究起点和作者源码许可证见 THIRD_PARTY_NOTICES.md。
